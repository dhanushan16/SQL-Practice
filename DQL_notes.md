# DQL (Data Query Language)

## What is DQL?

DQL stands for **Data Query Language**.

DQL is used to **retrieve or fetch data from the database**.

The main command used in DQL is:

- SELECT

DQL only retrieves data and does not modify the data stored in the table.

---

# SELECT Command

## Definition

`SELECT` is a DQL command used to retrieve or fetch existing data from one or more tables based on the user's requirement.

It only displays the data and does not insert, update, or delete records.

---

## Syntax

```sql
SELECT column_name
FROM table_name;
